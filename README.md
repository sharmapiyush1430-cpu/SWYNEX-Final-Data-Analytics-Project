# SWYNEX Final Data Analytics Project

## Project Overview
This project presents an end-to-end data analytics case study completed as part of the SWYNEX internship. It uses the Superstore sales dataset to explore sales performance, profitability, customer segments, and regional trends.

## Objectives
- Clean and prepare the sales dataset.
- Perform Exploratory Data Analysis (EDA) using Python.
- Build an interactive sales dashboard using Microsoft Power BI.
- Identify business insights to support data-driven decisions.

## Tools and Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Jupyter Notebook
- Microsoft Power BI
- GitHub

## Project Files
- `Sales_data_cleaning.ipynb` — Data cleaning and preparation.
- `SWYNEX_Exploratory_Data_Analysis.ipynb` — Exploratory analysis and visualizations.
- `SWYNEX_Interactive_Dashboard.pbix` — Interactive Power BI dashboard.
- `SampleSuperstore_Cleaned.csv` — Cleaned dataset used for analysis.

## Dashboard Features
The Power BI dashboard is designed to explore sales and profit performance, product categories, customer segments, and regional results. Interactive filters help users examine different parts of the business.

## Key Learning Outcomes
- Data cleaning and preprocessing.
- Exploratory data analysis and visualization.
- Dashboard development and business reporting.
- Communicating analytical findings clearly.

## How to Use
Download the repository files. Open the notebooks in Jupyter Notebook and open the `.pbix` file in Power BI Desktop to explore the analysis and dashboard.
